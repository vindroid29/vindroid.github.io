# Vinay Kumbhar Portfolio

Personal portfolio website for **Vinay Kumbhar — Senior Android Developer**.

## Deploy on GitHub Pages

1. Create a GitHub repository named `vindroid29.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Set Source to **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your website will be available at `https://vindroid29.github.io`.

## Included

Responsive dark portfolio, About, Skills, Experience, Projects, Awards, Education, Contact, GitHub and LinkedIn links, downloadable resume, and smooth animations.
