# VK Profile Website

A responsive personal profile/portfolio website designed for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, animations, cursor effect

## Personalize it
Open `index.html` and replace:
- About text
- Skills
- Projects and project links
- Experience / education
- Email address
- GitHub and LinkedIn links

To use a profile photo, you can add an image such as `profile.jpg` and replace the `VK` avatar in `index.html` with an `<img>` element.

## Publish on GitHub Pages
1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload these three website files.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your website will appear at:
`https://YOURUSERNAME.github.io`
